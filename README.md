# Khushi Kundoor’s portfolio

Personal portfolio covering software engineering experience, project case studies, and an interactive Mustang workshop.

[Live site](https://khushi-kundoor.vercel.app/)

The site uses static HTML, CSS, and JavaScript. The Mustang workshop uses a bundled Three.js renderer. See `dist/vendor/` for third-party licenses and model attribution.

Vercel hosts the site from `dist/`. The site files can be served directly without a build step. From the repository root, run:

```sh
python3 -m http.server 8000 --directory dist
```

Open [localhost:8000](http://localhost:8000/).
